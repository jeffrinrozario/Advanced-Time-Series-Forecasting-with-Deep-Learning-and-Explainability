# Advanced-Time-Series-Forecasting-with-Deep-Learning-and-Explainability

Acquired a multi-variate time series dataset and preprocessed it by applying necessary scaling, differencing and creating sequences suitable for deep learning model training. Began with selecting three well-known technology stocks (Apple, Microsoft, and Google) as the multi-variate time series dataset. These stocks are generally correlated, making them suitable for the task. The data is cleaned and the data is split into training and testing sets and applied `MinMaxScaler` to scale the features. Next step is to implement, train and hyperparameter-tune a deep learning model (LSTM) for multi-step-ahead forecasting and document the architecture choices, loss function and optimization strategy. Imported the required Keras layers for building the LSTM model and then defined its architecture, taking into account the input shape derived from the processed data. After the LSTM model architecture is defined and compiled, I proceeded  with training the model using the prepared training data and then evaluate its performance on the test set. To understand the model's performance on unseen data and to obtain forecasts in the original data scale, I had used the trained model to make predictions on the test data. Then, I had inverse transformed the scaled and differenced predictions and the actual test values back to their original scale and calculate common regression metrics (MAE, MSE, RMSE) to quantitatively evaluate the model's forecasting accuracy. Implemented the ARIMA model as a baseline, by importing the necessary ARIMA class from statsmodels. Then, I had iterated through each stock ticker, trained the ARIMA model on the scaled training data and generated predictions for the test period. Finally, I'd inverse transformed these predictions and evaluated the model's performance against the actual values. Implemented, trained and evaluated a Prophet model as a baseline for forecasting, applying it to each time series independently. Integrated a model interpretability framework (SHAP) to analyze feature importance on a subset of forecasts, focusing on explaining short-term prediction drivers. I had imported the shap library and prepared the background dataset (X_background) from X_train by sampling 100 random instances. Then, defined a prediction function that correctly reshapes the input for the LSTM model, and finally created the shap.KernelExplainer object using this prediction function and the X_background dataset. Conducted a comprehensive comparative analysis of the deep learning model against the baselines using appropriate metrics (RMSE, MAE, MAPE). Documented the findings regarding model stability and interpretability and visualize the results, ensuring legends are provided for all plots.
